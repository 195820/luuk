**代码待修项 N1（Critical，仅登记不修）**：
`src/main/services/job-runner.ts`：`shutdown()`（L165-173）置 aborted/paused + `runningJobs.clear()` 后 `await Promise.allSettled([...pendingExecutions])`（快照）；但被 abort 的 `executeJob` 收尾无条件 `this.pump()`（L281），此时 `runningJobs` 已空且退出路径不关 DB，`getPendingJobs()` 会复活其它 pending 作业并逃逸快照等待，与 `app.exit(0)` 抢写。修复方向（后续单独排期）：
```ts
private shuttingDown = false
async shutdown() { this.shuttingDown = true; /* abort/paused/clear */
  while (this.pendingExecutions.size) await Promise.allSettled([...this.pendingExecutions]) }
private pump() { if (this.shuttingDown) return; /* 原 size/has 双守卫 */ }
```
配套回归用例：`shutdown()` 后不得再 start 任何作业。
