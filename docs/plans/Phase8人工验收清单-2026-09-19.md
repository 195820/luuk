# Phase 8 AI 插件系统 · 人工验收清单

> 日期：2026-09-19 ｜ 分支：`fix/phase8-defects`（M1 c885f4d → M5 b1c83b7）
> 代码缺陷（P0-1~P2-19）已全部实施并自动化验证通过（tsc 无错 / vitest 393 用例绿 / build:dir exit 0）。
> 本清单覆盖**自动化测不到**的部分：真实交互、画质、内存/崩溃现场、批处理端到端。
>
> **图例**：`☐` = 待人工验证 ｜ `☑` = 已（自动/构建）验证通过。人工项完成后把 `☐` 改 `☑`；不通过标 `✗` 并在行尾附「现象+期望+日志」。

## 0. 环境准备
- ☐ `npm run dev` 成功启动（不想自动开 DevTools：设 `NO_AUTO_DEVTOOLS=1`）
- ☐ 导入测试库 `test-library/`（set01~set10）
- ☐ 另备 **真实含主体的人物照片** 若干（test-library 为生成图、无显著主体，不适合验抠图画质）
- ☐ 打开任务管理器 / 资源监视器（观察主进程 + 插件 Worker 内存）

## 1. 开启插件系统
- ☐ 设置 → **插件 Tab**：打开总开关 `plugins.enabled`；逐个启用 autotone / matting / upscale
- ☐ 设置 → **AI Tab**：下载模型（matting=u2netp、upscale=realesrgan-x4plus），进度条实时更新，完成后状态转「已下载」
- ☐ 【P2-17】模型未下载时，右键该 op **置灰并显示"需下载模型"**（非隐藏、非可点）
- ☐ 【P2-18】改了 `models.directory` 设置后**无需重启**，新路径即被使用

## 2. 单图 op（正确性主路径）
右键单张图 → AI op 逐个执行：
- ☐ **autotone**：曝光/色方合理变化，写进非破坏性编辑链（可撤销/对比原图）
- ☐ **matting**（真实照片）：边缘干净、背景透明、前景正确保留
  - ☐ 【P2-14 回归】近似常数的掩码**不被 min-max 拉爆/整体塌黑**（应保留绝对量纲）
- ☐ **upscale x4**：放大画质正常
  - ☐ 【P2-13 回归】灰度图放大**无伪彩色**（decode 强制 sRGB）
  - ☐ 【P2-13 回归】模型倍率与请求倍率不一致时应**报错**而非错位/溢出

## 3. 批处理链（P0-1，最易出"假成功"）
- ☐ 多选 **>20 张** 执行 op → 走后台作业队列（`jobsEnqueue`），弹入队 toast
- ☐ **JobProgressBar** 显示真实推进进度（非秒到 100%）
- ☐ 成功项落 `done`；损坏/不支持文件落 **可见的 `failed`**（不是静默 done）
- ☐ 【P1-9 回归】连续排 2 个作业：第 2 个在第 1 个结束后**自动拉起**，不永久 pending
- ☐ 【P1-9 回归】队列中取消队头 → 后续作业仍继续被拉起

## 4. 资源与稳定性
- ☐ 【P0-2】超大图 upscale 超像素预算 → **抛可展示错误**（提示改 2x / 先缩放），进程不崩
- ☐ 【P0-3】连续批处理下 RSS 接近红区（聚合 ~2500MB / Worker ~500MB）时触发驱逐、不 OOM
  - ☐ **阈值标定**：记录一次真实会话峰值 RSS，确认 1500/2500/500 是否贴合本机（遗留校准项）
- ☐ 【P1-6】制造 Worker 异常 → 恢复后已启用插件**自愈重载**，无需重启 app
- ☐ 【P1-11】Worker 崩溃后 `loadedInWorker` 不残留陈旧状态（不出现"显示已激活但实际未加载"）
- ☐ 【P1-7 回归】批处理中 SDK 卡住 → 按分级/动态超时返回（写盘按 payload 字节放大），不永久挂起
- ☐ 【P1-10】内存压力/切插件后，会话按 LRU 驱逐；同名模型并发只建一个会话

## 5. 权限与安全
- ☐ 【P1-4】正常 op 不会把文件写到库目录之外（edit.write 路径守卫）
- ☐ 【P1-5】同时触发多插件不串位（权限各用自身 pluginId）
- ☐ 【P2-12】`createSession` 传入外部/越权 modelPath 被忽略，未授权模型不可复用

## 6. 崩溃/退出健壮性
- ☐ 【P1-6 / P1-11】重启 Worker 后旧实例的延迟 exit 事件不污染新实例
- ☐ 【P1-8】模型状态持久：重启 app 后已下载模型仍为「已下载」（不被 verifyModel 误删）
  - ☐ 空 sha256 的模型：文件存在时**只验存在性、不删文件**并回写状态

## 7. 交付出口（已自动验证）
- ☑ `tsc --noEmit` 无 error
- ☑ `npx vitest run` 全绿（当前 43 文件 / 393 用例）
- ☑ `npm run build:dir` exit 0（win-unpacked 生成，builtins 三插件产物校验通过）
