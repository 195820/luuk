## 📥 安装问题

### Electron 下载失败

**问题**: 安装依赖时 Electron 下载失败

**解决方案**:

```bash
# 项目已配置 .npmrc 使用镜像源
# 如仍有问题，手动设置镜像
npm config set electron_mirror https://npmmirror.com/mirrors/electron/

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### sharp 安装失败

**问题**: sharp 模块安装失败

**解决方案**:

```bash
# 确保使用 Node.js 22+
node -v

# 重新安装 sharp
npm rebuild sharp
```

## ▶️ 运行问题

### 应用无法启动

**问题**: 运行 `npm run dev` 后应用未启动

**排查步骤**:

1. 检查控制台错误信息
2. 检查端口是否被占用
3. 清理缓存后重试

```bash
rm -rf dist dist-electron node_modules/.vite
npm run dev
```

### 开发模式白屏

**问题**: 应用启动后显示白屏

**解决方案**:

1. 打开 DevTools 查看控制台错误
2. 检查 React 组件是否有运行时错误
3. 清理后重新启动

```bash
npm run clean
npm install
npm run dev
```

## 🚀 性能问题

### 缩略图加载慢

**问题**: 首次加载缩略图速度较慢

**说明**: 首次扫描需要生成缩略图缓存，属正常现象。后续加载会从缓存读取。

**优化建议**:

- 首次扫描后不要删除 `.ivlib` 目录
- 大库建议等待完整扫描完成

### 内存占用高

**问题**: 应用内存占用过高

**解决方案**:

```bash
# 检查缓存统计
const stats = await window.electronAPI.getCacheStats();
console.log(stats);

# 清理缓存
await window.electronAPI.clearCache();
```

**建议**: LRU 缓存上限为 200MB，如仍过高请报告 issue。

2. 检查数据库完整性

## ❓ 常见问题 FAQ

### Q: 如何添加新库？

A: 点击"管理"按钮 → 选择图片文件夹 → 自动扫描并添加

### Q: 缩略图缓存在哪？

A: 每个库的 `.ivlib/thumbs.db` 文件中

### Q: 如何清理缓存？

A: 删除对应库的 `.ivlib` 目录，重新扫描即可

### Q: 支持哪些图片格式？

A: JPG, PNG, GIF, WebP, BMP, TIFF

### Q: 如何备份数据？

A: 备份以下文件：
- `%APPDATA%\luuk\master.db`（主数据库）
- 各库的 `.ivlib\thumbs.db`（缩略图缓存）

### Q: 如何迁移数据到新电脑？

A:
1. 复制图片文件到新位置
2. 安装应用
3. 重新添加库（指向新路径）

### Q: 快捷键不生效？

A:
1. 确保焦点在应用窗口内
2. 检查是否与其他软件冲突
3. 重启应用

### Q: 图片旋转方向错误？

A: 应用会自动读取 EXIF 方向信息，如仍有问题请报告 issue。

### Q: 收藏数据如何导出？

A: 收藏数据存储在 `master.db` 中，可使用 SQLite 工具导出：

```sql
SELECT * FROM favorites;
SELECT * FROM favorite_folders;
```

## 🎬 视频播放问题记录

### 问题 1: Space 键冲突（幻灯片 vs 视频播放）

**严重性**: 中
**文件**: `src/App.tsx:639` + `src/components/ImageViewer.tsx:291`

**现象**:
- `App.tsx` 中 Space 键 → `toggleSlideshow()`（查看器模式下）
- `ImageViewer.tsx` 中 Space 键 → `toggleVideoPlayback()`（视频模式下）
- 两个事件监听器**都会执行**，导致播放视频时 Space 同时触发幻灯片切换

**修复建议**:
在 `ImageViewer.tsx` 的 Space handler 中添加 `e.preventDefault()` 阻止冒泡，或在 App.tsx 中判断当前是否为视频模式。

### 问题 2: 收藏夹无媒体筛选器

**严重性**: 低
**文件**: `src/App.tsx:995`

**现象**:
- 媒体筛选器 (`MediaFilter`) 仅在 `isFavoriteLibrary && viewMode === 'grid'` 时显示
- 当收藏夹包含视频/音频时，用户无法按媒体类型筛选

**修复建议**:
确认 `MediaFilter` 在收藏夹网格视图中的渲染条件是否正确。

### 已修复问题

#### 修复 1: 视频无法播放（data URL 方案）

**原问题**: Chrome 媒体管道不支持自定义 `luuk-file://` 协议，视频始终显示加载失败。
**修复**: `getMediaUrl` IPC 改为返回 base64 data URL，Chrome 原生支持。
**涉及文件**: `src/main/ipc/library-handlers.ts`, `electron/main.ts`

#### 修复 2: 视频加载永远卡在 loading 状态

**原问题**: `<video>` 元素缺少 `onError` 处理，加载失败时 `loadingState.loading` 永远为 true。
**修复**: 添加 `handleVideoError` 回调，失败时正确设置错误状态。
**涉及文件**: `src/components/ImageViewer.tsx`

#### 修复 3: 视频被当作图片加载

**原问题**: 收藏夹中 `mediaType` 字段映射缺失，视频被当作图片通过 `loadFullImage` 加载。
**修复**: 收藏夹 grid 映射增加 `fav.mediaType || fav.media_type || 'image'` 兜底检测。
**涉及文件**: `src/App.tsx`

#### 修复 4: 库路径包含回车符导致安全检查失败

**原问题**: 数据库中库路径 `root_path` 包含 `\r`（0x0d），导致 `startsWith` 比较永远失败。
**修复**: `mapLibrary` 中使用 `.trim().replace(/\r/g, '')` 清理路径。
**涉及文件**: `src/main/services/database.ts`
