### 4. 数据层

**职责**：数据存储和检索

#### 数据库架构

**主数据库 (master.db)**

位置：`%APPDATA%\luuk\master.db`

```sql
-- 库列表
CREATE TABLE libraries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    root_path TEXT UNIQUE NOT NULL,
    status TEXT DEFAULT 'offline',
    last_scan TEXT,
    image_count INTEGER DEFAULT 0,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 跨库收藏
CREATE TABLE favorites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    library_id INTEGER NOT NULL,
    image_path TEXT NOT NULL,
    tags TEXT,
    rating INTEGER DEFAULT 0,
    note TEXT,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(library_id, image_path)
);

-- 收藏文件夹
CREATE TABLE favorite_folders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    library_id INTEGER NOT NULL,
    folder_path TEXT NOT NULL,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(library_id, folder_path)
);
```

**分库数据库 (thumbs.db)**

位置：`{库目录}\.ivlib\thumbs.db`

```sql
-- 图片元数据
CREATE TABLE images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    relative_path TEXT UNIQUE NOT NULL,
    file_hash TEXT,
    width INTEGER,
    height INTEGER,
    file_size INTEGER,
    format TEXT,
    media_type TEXT DEFAULT 'image',  -- 'image' | 'video' | 'audio'
    duration REAL DEFAULT NULL,       -- 时长（秒），图片为 NULL
    codec TEXT DEFAULT NULL,          -- 编码格式
    orientation INTEGER DEFAULT 1,
    created_time TEXT,
    modified_time TEXT,
    indexed_time TEXT,
    is_deleted INTEGER DEFAULT 0
);

-- 缩略图缓存
CREATE TABLE thumbnails (
    image_id INTEGER NOT NULL,
    size TEXT NOT NULL,  -- small/medium/large
    data BLOB NOT NULL,
    width INTEGER,
    height INTEGER,
    generated_at TEXT DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (image_id, size)
);
```

## 🔌 媒体加载策略

所有媒体类型（图片/视频/音频）统一通过 `getMediaUrl` IPC 返回 `media://TOKEN` URL，避免全量 base64 加载导致大文件 OOM。

### media:// 自定义协议（当前实现）

**注册位置**：`electron/main.ts` → `protocol.registerSchemesAsPrivileged`（standard/secure/supportFetchAPI），协议处理器 `fs.promises` 直读文件并支持 HTTP Range 请求（视频 seek 必需）。

**工作原理**：
1. 前端调用 `getMediaUrl` IPC → 后端将库路径内的文件映射为随机**小写 hex 令牌**，存入 `src/main/services/media-registry.ts`
2. URL 形如 `media://HEXTOKEN`，渲染进程通过 `<img>` / `<video>` / `<audio>` 或 fetch 加载
3. 协议处理器用令牌查表得到真实路径，直读文件流

**令牌机制动机**：Chromium 的 WHATWG URL 解析会对 URL authority 部分强制小写化，破坏 base64 编码的大小写敏感性；令牌全为小写 hex 不受影响（详见 [多媒体模块重构方案](../archive/多媒体模块重构方案.md)）。

**安全检查**：IPC 处理器限制访问范围在已注册库路径内；库路径从数据库读取时使用 `.trim().replace(/\r/g, '')` 清理不可见字符。

**支持的媒体格式**：
- 视频：mp4, webm, mov, avi, mkv
- 音频：mp3, wav, flac, aac, ogg, m4a

> **历史**：早期用 data URL 全量 base64（500MB 视频 → 667MB 内存，OOM），重构时废弃；`luuk-file://` 自定义协议为死代码已清理。

### 2. ImageService

**文件**：`src/main/services/image-service.ts`

**职责**：
- 图片元数据管理
- 缩略图缓存（LRU 200MB）
- 缓存 Key 格式：`${libraryId}-${imageId}`
- **媒体类型判断**：`getMediaTypeFromPath()` 基于文件扩展名（比数据库 `media_type` 更可靠）

**使用示例**：
```typescript
const images = await ImageService.getInstance()
  .getImages(libraryId, options);
// 返回的每个 image 包含 mediaType: 'image' | 'video' | 'audio'
```

**媒体类型判断逻辑**：
```typescript
private getMediaTypeFromPath(relativePath: string): 'image' | 'video' | 'audio' {
  const ext = path.extname(relativePath).toLowerCase();
  const videoExts = new Set(['.mp4', '.webm', '.mov', '.avi', '.mkv', '.m4v']);
  const audioExts = new Set(['.mp3', '.wav', '.flac', '.aac', '.ogg', '.m4a']);
  if (videoExts.has(ext)) return 'video';
  if (audioExts.has(ext)) return 'audio';
  return 'image';
}
```

## 🎨 核心组件

### 查看器

**外壳**：`src/components/ImageViewer.tsx` — 导航（←/→）、全屏、快捷键分发、媒体类型路由

**功能**：
- **图片/GIF**：`ImageLightbox.tsx`（YARL）— 缩放 0.1-10x、旋转 90° 步进、翻转、适应窗口/实际大小、幻灯片（3/5/10/30s）
- **视频**：原生 `<video>` + 自定义控件 — 播放/暂停/seek/音量，Space 切换播放，不支持格式显示占位提示
- **音频**：`AudioViewer.tsx`（wavesurfer.js）— 波形可视化 + 交互式定位
- 媒体类型由 `mediaType` 字段（`getMediaTypeFromPath` 按扩展名判定）自动路由，统一 `media://` 加载

### 网格视图

**文件**：`src/components/ImageGrid.tsx`

**功能**：
- 虚拟滚动（@tanstack/react-virtual）
- 懒加载（只渲染可见区域）
- 缩略图尺寸调节（80-400px）
- 滚动位置记忆

### 瀑布流视图

**文件**：`src/components/MasonryGrid.tsx`

**功能**：
- 根据图片高度自适应布局
- 更紧凑的排列效果

### 文件夹树

**文件**：`src/components/FolderTree.tsx`

**功能**：
- 递归展示文件夹层级
- 展开/折叠
- 图片计数（包含子文件夹）
- 点击筛选图片
