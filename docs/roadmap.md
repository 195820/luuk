## 一、高优先级任务 (P0)

### 0. 多媒体支持（视频 + 音频 + 图片统一管理）✅ 已完成

- **实施**：2026-06-22 完成，包括 `media://` 令牌流式加载、wavesurfer.js 音频波形、YARL 图片 lightbox、组件分离（ImageLightbox/AudioViewer/AudioPlayer）、收藏媒体筛选。
- **记录**：方案与验收见 [archive/多媒体模块重构方案.md](archive/多媒体模块重构方案.md)、[archive/多媒体模块重构测试计划.md](archive/多媒体模块重构测试计划.md)。

### 1. 快速预览面板 (Quick Look) ⬜

双击打开查看器是"重操作"，快速预览提供轻量的弹窗查看方式（类似 macOS 空格键预览）。

- 网格视图选中一张图 → 按空格 → 屏幕中央弹出浮层显示大图
- 浮层内 `←/→` 切换上一张/下一张，含收藏按钮
- 再按空格或 `Esc` 关闭
- **预计工时**：0.5 天
- **涉及文件**：`src/components/QuickPreview.tsx`（新）、`src/App.tsx`

### 2. 高级搜索面板 ⬜

顶部搜索入口，多维度组合搜索：文件名模糊、尺寸范围、文件大小、格式、拍摄日期范围、收藏状态/评分/标签。

- **预计工时**：1 天
- **涉及文件**：`database.ts`（加搜索方法）、`library-handlers.ts`、`SearchPanel.tsx`（新）、`searchStore.ts`（新）

### 3. 设置壁纸 ⬜

一键将当前图片设为 Windows 桌面壁纸，支持填充/适应/拉伸模式。

- **预计工时**：0.5 天
- **新增依赖**：`npm install wallpaper`
- **涉及文件**：`wallpaper-service.ts`（新）、`ImageViewer.tsx`（工具栏按钮）、右键菜单

### 4. 图片文件操作 ⬜

应用内复制/移动/重命名/删除图片、在资源管理器显示。删除走系统回收站。

- **预计工时**：1 天
- **新增依赖**：`npm install trash`
- **涉及文件**：`file-service.ts`（新）、`library-handlers.ts`、网格/查看器右键菜单

### 5. 增量扫描优化 🟡

进度：`scanner.ts` 已按 `modified_time` 跳过未变文件。缺两项增强：

- 用「文件大小 + 修改时间」双条件快速跳过未变动文件
- 文件夹级别增量检测（只扫描变动的子文件夹）
- 预期提升：增量扫描速度 **80-90%**
- **预计工时**：0.5 天
- **涉及文件**：`src/main/services/scanner.ts`

### 6. 浏览历史 ⬜

进度：`master.db` 的 `history` 表与 `image-service.addHistory()` 已实现，**缺 IPC 暴露、preload 接口与 UI**（"最近浏览"视图）。

- 记录最近浏览的 100-500 张图片，提供"最近浏览"视图、快速返回上次浏览位置
- **预计工时**：0.5 天
- **涉及文件**：`library-handlers.ts`、`preload.ts`、`historyStore.ts`（新）、`AppSidebar.tsx`

> 📌 **收尾建议**：6 项 P0 中「快速预览 + 浏览历史 + 评分接入」均为半天内小活，可优先把第一轮清完（见[推荐执行顺序](#九-推荐执行顺序））。

## 六、特色功能建议

### 39. 智能收藏推荐

根据浏览行为（停留时间长、放大查看、反复回看）自动标记"可能喜欢"的图片，提供一键收藏入口。纯行为分析，无需 AI 模型。

- **预计工时**：1-2 天

### 40. 自定义相册

用户可创建多个相册（类似播放列表），跨文件夹、跨库把相关图片归入逻辑分组，支持自定义排序、拖拽调整顺序、封面设置。与收藏的区别：收藏是"我喜欢"（扁平聚合），相册是"同主题归档"（可排序可命名）。

- **预计工时**：2-3 天
- **数据库设计**：

```sql
CREATE TABLE albums (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    cover_image_id INTEGER,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE album_items (
    album_id INTEGER NOT NULL,
    library_id INTEGER NOT NULL,
    image_id INTEGER NOT NULL,
    sort_order INTEGER NOT NULL,
    added_at TEXT DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (album_id, library_id, image_id),
    FOREIGN KEY (album_id) REFERENCES albums(id) ON DELETE CASCADE
);
```
